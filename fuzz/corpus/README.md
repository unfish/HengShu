# 长期模糊测试语料

此目录只保存人工挑选的最小输入，不保存 `cargo fuzz` 运行时自动生成的
`artifacts/`、覆盖率数据库或临时输出。新增语料必须能说明覆盖的边界：

- `source_pipeline/`：UTF-8、嵌套、格式化和资源预算边界源码。
- `bytecode_loader/`：截断、尾随字节、错误跳转和超大载荷。
- `automation/`：事件、日历表达式、状态记录和通知 JSON。
- `pdf/`：表格、SVG、字体和分页 IR 的最小序列化输入。
- `ooxml/`：合并单元格、关系顺序、日期系统和拒绝的活动部件。

5 秒 smoke 不应写回本目录；定期 fuzz 作业提交前先去重并保留最小崩溃样本。
