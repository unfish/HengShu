# 角色配方

这些程序模拟真实工作流，每条都使用内置小样本，首次运行无需准备数据：

- `财务对账月报.代码`：流水/台账对账、差异清单、PDF 与模板替换。
- `HR工资条批量.代码`：员工、薪资、扣缴三表连接，敏感字段脱敏后生成工资条。
- `销售排名排程.代码`：销售排名、区域透视、PDF 周报和可外发摘要。
- `老板经营报告.代码`：支持 CLI/GUI 传入 CSV，生成经营指标、图表和 PDF。
- `老师成绩单批量.代码`：成绩计算、班级小样本保护、假名化成绩单。
- `公务员汇总退回.代码`：脏数据校验、退回原因、原格式公文替换。
- `医生病例检验.代码`：病例假名化、分箱、组间检验和脱敏报告。

真实环境中请把网络通知、SMTP 和敏感端点写入项目 `衡枢.toml`，示例本身不会自动外发数据。
