# 衡枢示例

从根目录入口开始：

```bash
衡枢 检查 examples/成绩分析.代码
衡枢 运行 examples/销售分析.代码
衡枢 测试 examples/自动化测试.代码
```

`语法/` 是按语言能力组织的主题分册，适合逐个阅读；`角色配方/` 是贴近实际岗位的端到端流程。示例默认使用内置数据，运行产生的结果目录已被 `.gitignore` 忽略。

AI 示例默认使用 `模拟` 或 `离线` 模式，不联网也能复现。需要在线调用时，复制 `环境.配置.模板` 为 `环境.配置`，填写真实值，再把示例中的 `模式` 改为 `在线`。真实配置文件已加入忽略规则，切勿提交密钥。

`AI结构化提取.代码` 是在线示例：字段定义会转换为严格 JSON Schema，模型结果中的对象数组会直接成为表格并保存为 CSV。
