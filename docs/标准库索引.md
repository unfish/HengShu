# 标准库索引

| 模块 | 主要接口 |
|---|---|
| 文件系统 | 读取文本、读取字节、写入文本、追加文本、复制、移动、删除、遍历、逐行读取 |
| 路径处理 | 拼接、绝对路径、规范化、当前目录 |
| 编码 | 转字节、转文本、Base64编码、Base64解码、十六进制编码、十六进制解码 |
| JSON | 解析、生成、读取行、写入行 |
| TOML | 解析、生成 |
| 日期时间 | 现在、今天、解析、格式化、增加、相差 |
| 环境 | 读取、设置、全部、当前目录、程序参数、平台 |
| 进程 | 执行，支持工作目录、环境和超时 |
| 正则 | 是否匹配、查找、查找全部、替换、分割 |
| 压缩 | Gzip压缩、Gzip解压 |
| 网络 | 解析URL、拼接URL、请求、自动识别响应字符编码、表单、multipart 文件上传、代理、重试、取消文件、连接TCP、监听TCP、绑定UDP |
| 网页 | CSS 选择器文本/HTML/属性提取、记录提取、Chrome 动态页面分页抓取、随机翻页等待、动态内容就绪条件 |
| 数据库 | 打开SQLite、驱动能力；执行、批量参数、查询、流式查询和事务 |
| 密码 | 安全随机字节、SHA256、HMAC_SHA256、恒定时间相等 |
| 日志 | 记录、调试、信息、警告、错误；轮换字节、保留份数 |
| 表格处理 | 读取表格、读取CSV流、流式多维汇总、把记录整理成表格、写入表格、CSV/Parquet 分区写出、连接、透视、排名、滚动统计、列单位设置/查询、列敏感设置/查询、标记列脱敏/标记列假名、schema 单位校验 |
| 统计分析 | 数组、数据概览、期间比较、贡献/Pareto、队列/漏斗、稳健描述统计、异常检测/排除/缩尾、预测误差、多模型需求预测、ADI/CV² 稳定性、安全库存、批量商品预测、检验（含配对、Spearman、Fisher、多重校正）、回归、时间序列、优化、读取Parquet流、Parquet/CSV 分块 |
| 财务 | 金额、税额、汇率、审计、会计期间、工作日、敏感性分析 |
| 图表/报告 | 带分类轴、刻度、单位、标签、参考线、区间带和注释的折线图、柱状图、散点图、直方图和箱线图；类型感知表格和指标报告；导出 CSV/XLSX/HTML/SVG/PDF |
| 交付 | `Word转PDF(模板路径，输出路径，变量记录)`；`模板替换(模板路径，输出路径，变量记录)` 保留原始 XLSX/DOCX 包，键写成 `工作表!单元格` 时替换 XLSX 单元格，否则按 DOCX 占位符替换；内置转换基础段落、表格、分页符和页眉页脚，不依赖 Office |
| 隐私 | `掩码(文本)` 默认全掩，`保留前`/`保留后` 只能选一个；`假名化(文本，密钥)` 输出稳定摘要；`分箱(值，宽度)` 把连续值归入区间下界 |
| 对账 | `比对(左表，右表，规则记录)` 返回状态/左编号/右编号/评分/差异表，规则记录支持 `编号字段`、`精确键`、`比较字段`、`金额字段`、`绝对容差`、`相对容差`、`日期窗口`、`模糊字段`、`模糊阈值`、`候选上限` 和 `版本`；`统计(结果表)` 按状态计数 |
| 并发 | 启动、等待全部、通道、通道转流、任务组、并行映射、休眠 |
| 人工智能（实验性） | 配置、请求（在线/记录/重放/模拟/离线）、模拟响应、分析结论、生成报告、提取结构化；普通请求保持文本返回，分析与提取按场景使用严格 JSON Schema；提取结果的对象数组直接转换为表格；Responses 兼容图片/PDF 输入、detail 选项、失败回退和可编辑 HTML 模板；参数从源码或打包目录的 `环境.配置` 读取 |

所有文件、网络、环境、进程和输出文件接口都受权限模型控制。HTTP 响应的 `设置Cookie` 属性保留全部同名 `Set-Cookie`，但不会自动跨域发送。`网页 逐页采集` 需要本机 Chrome 或 Chromium，同时需要目标网络权限和 `子进程` 权限；它不处理登录、验证码或站点私有加密协议。
