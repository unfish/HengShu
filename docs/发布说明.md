# 0.9 发布说明

本文件列出 0.9 对外可见的支持范围和限制。用法见 [用户手册](用户手册.md) 和 [标准库索引](标准库索引.md)，发布步骤见 [发布清单](发布清单.md)。

## 模板替换支持矩阵

`交付 模板替换(模板路径, 输出路径, 变量记录)` 在原始 OOXML 包上定点写入，不重新排版，不依赖 Office。

| 对象 | 状态 | 说明 |
|---|---|---|
| XLSX 单元格 | 支持 | 变量键写成 `工作表!单元格`，如 `汇总!B2`；单元格引用不区分大小写 |
| XLSX 命名区域、表格锚点、样板行 | 支持（Rust API） | `delivery_template` 的计划接口可用；`交付 模板替换` 的记录键目前只覆盖 `工作表!单元格` 和 DOCX 占位符 |
| XLSX 公式与缓存值 | 保留 | 相对/绝对引用原样保留，公式缓存值缺失时按预检规则处理 |
| DOCX 占位符 | 支持 | 变量键为占位符文本，跨 run 的占位符会先合并再替换 |
| DOCX 内容控件 | 支持（Rust API） | 按控件 `w:val` 标签定位；DSL 记录键走占位符路径 |
| DOCX 页眉、页脚 | 支持 | 与正文使用同一替换规则 |
| VBA、宏、OLE、嵌入对象 | 拒绝 | 写出前失败，绝不执行主动内容 |
| 外部链接、远程关系 | 拒绝 | 不做网络解析；按 `.rels` 的关系 `Type` 判定，普通超链接仍允许 |
| 未声明的 OOXML 部件 | 原样复制 | 不改写、不假成功 |
| ZIP 路径穿越、XML 实体、压缩包超限 | 拒绝 | 命中安全边界或资源预算即失败 |

`替换数` 的含义按目标类型不同：DOCX 路径返回实际替换的占位符和控件数量，XLSX 路径返回被改写的包内部件数量。

## 报告 PDF 支持范围

`报告 导出(报告, "PDF", 路径)` 使用有限的 `ReportDocument` 布局 IR，先预检再写出。

| 对象 | 状态 | 说明 |
|---|---|---|
| 固定页尺寸、页边距、段落、表格、页眉页脚 | 支持 | 超出页/元素/文本/输出预算时预检失败 |
| 显式分页与跨页表头重复 | 支持 | 表头在每页重复 |
| 长文本换行 | 支持 | 按字符宽度换行，不做断词优化 |
| 中文文本 | 支持 | Noto Sans SC 作为 OFL 编译期资源嵌入单一可执行文件，由 `printpdf 0.12.6` 生成字体映射与子集；不读取系统字体 |
| JPEG/PNG 图片 | 支持 | PNG 解码为 RGB 后嵌入，按声明坐标定位；尺寸为零或超预算时失败 |
| 指标区、表格、列表、图表章节 | 支持 | 图表章节引用同目录下已生成的 SVG |
| 任意 XLSX/DOCX 转 PDF | 不支持 | 模板替换和报告 PDF 是两条独立流程 |
| 自定义字体子集、透明度、矢量图形、书签 | 不支持 | 预检直接拒绝，不静默降级 |

`交付 Word转PDF` 只转换基础段落、表格、分页符和页眉页脚，不覆盖完整 DOCX 排版。

## GUI 与 CLI 产物差异

两种产物共用同一套解析后语义、诊断、权限和资源预算，差别只在宿主：

| 方面 | CLI 产物 | GUI 产物 |
|---|---|---|
| 打包命令 | `衡枢 打包 <源> -o <输出>` | 同一命令加 `--界面` |
| 载荷类型 | `PackageKind::Cli` | `PackageKind::Gui` |
| 参数来源 | 命令行参数与 `--参数 名称=值` | 窗口控件按工具 schema 生成 |
| 输出 | 标准输出与退出码 | 结果页四个标签页：输出、交付物、过程、诊断 |
| 平台封装 | 可执行文件；Linux 另可生成 AppImage | macOS `.app`、Windows `.exe`、Linux AppDir |
| 无图形环境 | 正常运行 | 无法创建窗口 |

载荷版本为 14、字节码版本为 13。载荷 14 在 CLI 工具描述中新增可选 `AutomationSpec`，已安装任务可在删除源码后完成 IANA 时区判定、文件扫描、历史和通知。`衡枢 验证包` 校验载荷类型、版本、模块和工具 schema。打包时权限固化进载荷，运行时不能再扩大；载荷尾部的 SHA-256 只用于发现损坏，不是抗篡改签名。

带敏感标签的数据外发必须同时获得 `["权限"]."允许端点"` 与 `"允许敏感类别"` 授权。源码、字节码、GUI 和独立包使用同一策略；未授权时会在实际外发前报告“端点未授权”。如需外发，请在 `衡枢.toml` 的 `"允许端点"` 中声明目标（例如本地文件使用 `"LocalFile"`），或先用 `隐私 掩码`/`隐私 假名化` 处理并用 `标记列脱敏`/`标记列假名` 记录状态。

## 复算限制

`衡枢 存证` 写出凭证（凭证版本 2），`衡枢 复算 <凭证> --输入根 <目录>` 重放并比较结果。

- 复算比较输出、退出状态和输入指纹；输入内容或程序摘要变化时在对应阶段失败，不会给出“大致相同”的结论。
- 外部依赖分三级：`None` 无外部依赖，`FingerprintOnly` 只记录指纹无法重放，`Replayed` 可完整重放。含 `FingerprintOnly` 依赖的运行不能声称完全复算。
- 网络响应、子进程输出、当前时间和随机数不被记录为可重放输入，只能降级为指纹。
- 凭证不是签名：能改写凭证文件的人可以同时改写摘要，抗篡改要由分发渠道提供。
- `衡枢 验证凭证` 在缺少 `EvidenceView` 端点授权时只打印计数，参数值和输出行替换为占位符。

## Webhook 限制

自动化通知里的 Webhook 只做一件事：向声明的地址发一次 POST。

- 只允许 POST，方法不可配置。
- 不跟随重定向；返回 3xx 视为失败，且错误文本不包含签名或密钥。
- 非 2xx 视为失败；Webhook 本身不自动重试，SMTP 仅对临时错误按任务重试次数重试。
- 地址必须在网络权限允许范围内，敏感数据外发还要通过 `Webhook` 端点授权和敏感类别授权。
- 不内置任何服务商协议适配，摘要内容由程序决定，建议只放汇总量而不是明细。

## Notebook 格式版本

- 过程报告 JSON 的 `NOTEBOOK_VERSION` 为 1，事件包含步号、阶段、描述和有限摘要。
- 观察模式分 `关闭`、`摘要`、`快照`、`详细`；`关闭` 时无额外开销，其余模式受事件数量和顺序预算限制，超限截断并标记。
- 关闭观察不改变程序结果：同一程序在任何观察模式下输出一致。
- 报告是数据，不具备执行能力；删除报告不影响程序运行。
- 敏感值在事件里按标签遮挡，HTML 查看器对内容做转义且不含脚本。

## 格式版本与兼容性

| 格式 | 常量 | 当前版本 |
| --- | --- | --- |
| 字节码 | `BYTECODE_VERSION` | 13 |
| 独立包载荷 | `PAYLOAD_VERSION` | 14 |
| 运行凭证 | `EVIDENCE_VERSION` | 2 |
| 过程报告 | `NOTEBOOK_VERSION` | 1 |
| 表格单位 schema | `写入表格` 的 `单位schema` 输出 | 1 |

- 可移植值携带数量的单位/口径和表格的表级、列级元数据；任务与通道是进程内句柄，不参与跨进程编码。
- 单位/口径语义按记录编译，不新增字节码指令，因此不使用单位的旧程序在解释器、VM 和独立包上行为不变。
- 版本不匹配时按结构化错误拒绝载荷或凭证，不退化为普通命令行工具。
