# 数据语义约定

本文规定衡枢 0.9 在数值数组、表格和统计分析中的共同数据语义。实现和测试应以这些规则为准，新增功能不得自行引入冲突规则。

## 缺失值

- 表格缺失值使用 `空`；CSV 空字段读取为 `空`。
- 数值数组使用非有限浮点值表示导入数据中的无效数值，统计操作在计算前过滤这些值。
- 过滤后没有有效数据时，统计操作返回结构化运行错误，不返回空统计量、NaN 或无穷。
- `填补缺失` 和 `去除缺失` 是显式转换；其他操作不得静默把缺失值改成零。

## 数值有限性

- 用户可观察的统计量、回归结果、检验统计量、P 值、累计结果和表格汇总必须是有限数值。
- Decimal 算术使用受检运算；溢出、除零和取模零返回语言级错误。
- 需要整数的参数必须没有小数部分并且位于目标整数范围内。索引、容量、块大小、工作者、超时、重试次数和窗口大小均适用此规则。
- 退化样本（例如零方差、自由度不足、不可逆矩阵）返回说明原因的错误，不构造无效分布。

## 表格混合类型

升序排序使用稳定的类型层级：

1. 数字、浮点数和金额
2. 日期时间和持续时间
3. 文本和路径
4. 逻辑值
5. 其他结构值
6. `空` 或不存在的列值

同类值按原始类型比较；数字列不转成文本比较。不同类型先按上述层级排序，再以文本表示作为确定性的次级规则。降序对完整结果反转，因此 `空` 位于开头。

## 数据概览

数据概览逐列给出 `列/类型/数量/有效数量/缺失数量/缺失率/唯一值/高频值/高频值截断/高频值覆盖率/单位/敏感标签`，数值列另有 `最小值/最大值/平均值/标准差/P25/中位数/P75/四分位距/异常数量/异常率`。结果级指标包含 `行数/列数/重复行/截断列数/异常值总数/敏感列数/来源数`，并附 `高频明细` 与 `字段说明` 两张规范化表。

- 概览行的单元格一律是标量：`高频值` 是文本摘要，完整频次放在 `高频明细`（`列/排名/值/数量/占比`）。`警告` 也是标量文本。这样概览结果能无损写进 CSV。
- 高基数列只保留 TopN，但必须置 `高频值截断` 并给出 `高频值覆盖率` 和警告；不得静默丢弃类别。
- 异常统计用四分位距法（`[P25−1.5×四分位距, P75+1.5×四分位距]` 之外），只统计不删除；`有效数量` 不会因为异常值而减少。
- 概览必须继承来源表的单位、来源和敏感标签。聚合与概览不得洗掉敏感标签，否则导出会绕过端点授权检查。

## 统计检验

所有检验返回同一套字段：`类型`、`方法`、`统计量`、`P值`、`自由度`、`样本量`、`缺失配对数`、`效应量名称`、`效应量`、`效应量判读`、`置信下限`、`置信上限`、`置信度`、`显著性`、`方法前提`、`警告`、`数字含义`。检验特有的业务估计量按其领域名称附加，例如 `均值差`、`相关系数`、`优势比`、`Z值`、`W统计量`。

- 结果字段一律是标量，不放嵌套记录、表格或多元素列表，这样同一份结果能无损写进 CSV，也能被报告列规范直接驱动。
- P 值必须位于 `[0, 1]`，统计量和 P 值都必须有限；自由度必须是正的有限值；置信区间必须有序（`置信下限 <= 置信上限`）。
- `显著性` 以 5% 为水平，必须与 `P值` 一致。`数字含义` 面向业务读者；不显著时必须说明这不等于两者相同，可能只是样本量不足，不得写成“已证明无差异”。
- `效应量判读` 的阈值按族系区分：标准化均值差（Cohen's d）用 0.2/0.5/0.8，关联强度（相关系数、Cramér's V、η²、phi）用 0.1/0.3/0.5。两族阈值不得混用。
- 无法给出的字段返回 `空`，不返回 0 或占位数字：例如非配对检验的 `缺失配对数`、零单元格下的 `优势比`、`|ρ|=1` 时的相关系数区间。
- 前提被违反时给 `警告` 而不是静默出数：期望频数小于 5、分组样本量过小、正态近似不可靠、配对因缺失被剔除都必须提示。夏皮罗-威尔克检验必须说明不显著不能反过来证明数据是正态的。
- t 检验、方差分析、夏皮罗-威尔克检验和相关系数在零方差或自由度不足时返回错误。
- 统计实现应同时具备已知答案测试和数学性质测试，例如平移不改变方差。

## 回归与预测

- 回归要求样本数量大于参数数量；系数、拟合值、显著性和拟合优度必须有限。
- 线性回归附带影响诊断：标准化残差、杠杆值、Cook 距离和 VIF，均复用同一个 `(XᵗX)⁻¹`。杠杆值之和等于参数个数；`VIF = (XᵗX)⁻¹_jj · Σ(x_ij − x̄_j)²`。残差方差为零时返回错误而不是无穷诊断值。
- 逻辑回归给出对数损失、准确率、混淆矩阵和秩和 ROC AUC；`RMSE` 是 Brier 风格的概率均方根误差，不是对数损失的平方根。只有一个类别时 AUC 报告 0.5，不报告 1。
- 诊断以规范化表格（`诊断`、`共线性`、`分类指标`）返回，单元格是标量。
- 预测必须按时间顺序验证，不得随机打乱时间序列；误差指标在实际值为零时返回有限结果或空值，不返回无穷值。
- 滚动验证的每一折用被选中的模型在时间前缀上重新预测，不得用上一期观测值冒充预测。汇总 RMSE 是平方误差均值的平方根，不是逐折 RMSE 的算术平均；汇总 WAPE 是误差总和除以实际值总和。实际值全为零时 WAPE 和可靠性返回 `空`。并列最差折取最早那一折。
- 异常值缩尾和排除必须保留原始顺序并报告边界、索引和数量；业务程序不得静默删除促销、断货或大客户事件。
- 周需求预测只使用完整自然周，缺失周按零需求补齐；安全库存必须明确服务水平、提前期、审查周期和库存位置口径。
- 预测验证必须先在原始时间轴上切分；异常边界、平滑参数和模型参数只能由训练段拟合。验证段不得参与任何训练统计量。
- 预测建模不得用“排除”删除周期；使用“不处理”或按训练边界“缩尾”，保证季节位置和留出边界不变化。
- 需求预测结果固定包含 `最佳模型/模型参数/预测/模型评估/验证指标/预测质量/异常周期数/建模序列/滚动验证/滚动汇总/预测下限/预测上限/区间置信度/区间方法/字段说明`。`模型参数`记录实际选中模型的窗口、季节周期或平滑系数；`字段说明`是`字段/说明`两列的规范化表格。
- 当前预测上下限采用名义 95% 的验证 RMSE 正态近似，即点预测加减 `1.96 × 验证RMSE`，下限截断到零。`区间置信度=0.95`，`区间方法=验证RMSE正态近似`；这是基于留出误差尺度的近似预测区间，不是模型参数的置信区间，也不保证未来观测有精确 95% 覆盖率。

## 容器与资源

- 列表、记录、集合和结构实例的相等关系必须自反；成员判断、去重、集合加入和匹配共用同一相等语义。
- 用户写入不能制造直接或间接循环引用。宿主预构造的循环值在显示和跨任务转换时必须返回占位文本或结构化错误，不得栈溢出。
- 所有集合扩容和物化路径使用项目配置的`最大集合项数`，包括范围、流、表格连接、数据库参数、报告、编码和统计分析。
- 超限检查在第一次非法写入或分配前发生；失败后原容器和事务状态不得出现越界的部分更新。
