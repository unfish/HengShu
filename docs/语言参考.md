# 衡枢语言参考

本文描述衡枢 0.9.0 的现行语法。旧控制流写法不保留兼容入口，只提供指向新写法的中文迁移诊断。

## 词法

源码使用 UTF-8 和 `.代码` 后缀。标识符可包含中文、英文字母、数字和下划线，不能以数字开头，也不能与保留字重名。字符串使用单引号或双引号，反斜杠转义下一个字符。注释从 `注：` 或 `注:` 开始直到行尾。

当前保留字：`公开`、`内部`、`任务组`、`定义`、`为`、`类型限定为`、`如果`、`否则`、`遍历`、`记作`、`当`、`时重复`、`尝试`、`捕获`、`最终`、`要求`、`否则说明`、`匹配`、`其他`、`并且满足`、`测试`、`测试准备`、`每项测试前`、`每项测试后`、`测试收尾`、`定义功能`、`结构`、`返回`、`跳出循环`、`继续下一轮`、`抛出`、`全局`、`引入`、`从`、`结束`、`类型是`、`的类型是`、`且`、`或`、`非`、`属于`、`不属于`、`的`、`之`、`输出`、`参数化输出`、`输入`、`自己`、`是`、`否`、`空`。

已移除但仍保留用于迁移诊断的词：`功能`、`否则如果`、`只要`、`就一直进行`、`中的每个`、`都进行`。

全角和半角的括号、逗号、冒号均可输入；格式化器统一为中文标点，字符串内容保持原样。

## 语法

以下 EBNF 中，换行用于分隔语句；圆括号、方括号和花括号内允许换行。每条语句必须以换行、分号或文件结束收尾，一行不能写两条语句；块的结束关键字可以紧跟同一行的最后一条语句，因此`定义功能（）：返回 1 结束`这样的单行内联块合法。

```ebnf
程序 = { 语句 } ;

语句 = 定义语句 | 赋值语句 | 表达式语句 | 条件语句 | 条件循环
     | 遍历语句 | 功能声明 | 返回语句 | 结构声明 | 导入语句
     | 全局语句 | 跳出语句 | 继续语句 | 尝试语句 | 抛出语句
     | 要求语句 | 匹配语句 | 测试语句 | 测试钩子 | 任务组语句 | 可见性语句 ;

定义语句 = "定义" 标识符 "为" 表达式 ["，" "类型限定为" 类型引用] ;
赋值语句 = 左值 "为" 表达式 ;
左值 = 标识符 | 属性表达式 | 索引表达式 ;
表达式语句 = 表达式 ;

条件语句 = "如果" 表达式 "：" 块
           {"否则" "，" "如果" 表达式 "：" 块}
           ["否则" "：" 块] "结束" ;
条件循环 = "当" 表达式 "时重复" "：" 块 "结束" ;
遍历语句 = "遍历" 表达式 "，" "记作" 标识符 "：" 块 "结束" ;

功能声明 = "定义功能" [类型引用] 标识符 "（" [参数列表] "）"
           ("：" 块 "结束" | "为" 表达式) ;
匿名功能 = "定义功能" "（" [参数列表] "）"
           ("：" 块 "结束" | "为" 表达式) ;
参数列表 = 参数 {"，" 参数} ;
参数 = 标识符 ["为" 表达式] ;
返回语句 = "返回" [表达式] ;

结构声明 = "结构" 标识符 "：" {标识符} "结束" ;
导入语句 = "引入" 模块名 | "从" 模块名 "引入" 标识符列表 ;
全局语句 = "全局" 标识符列表 ;
可见性语句 = ("公开" | "内部") (定义语句 | 功能声明 | 结构声明 | 导入语句) ;

跳出语句 = "跳出循环" ;
继续语句 = "继续下一轮" ;
任务组语句 = "任务组" "：" 块 "结束" ;

尝试语句 = "尝试" "：" 块
           ["捕获" [标识符] "：" 块]
           ["最终" "：" 块] "结束" ;
抛出语句 = "抛出" 表达式 ;
要求语句 = "要求" 表达式 ["的类型是" 类型引用]
           ["，" "否则说明" 表达式] ;

匹配语句 = "匹配" 表达式 "：" 匹配分支 {匹配分支}
           ["其他" "：" 块] "结束" ;
匹配分支 = "当" (表达式 | "类型是" 类型引用 | "记作" 标识符)
           ["，" "并且满足" 表达式] "：" 块 ;
测试语句 = "测试" (标识符 | 字符串) "：" 块 "结束" ;
测试钩子 = ("测试准备" | "每项测试前" | "每项测试后" | "测试收尾")
           "：" 块 "结束" ;

表达式 = 字面量 | 标识符 | 列表 | 记录 | 匿名功能
       | 一元表达式 | 二元表达式 | 调用表达式 | 属性表达式 | 索引表达式 ;
列表 = "[" [表达式 {"，" 表达式}] "]" ;
记录 = "{" [记录项 {"，" 记录项}] "}" ;
记录项 = (标识符 | 字符串) ":" 表达式 ;
调用表达式 = 表达式 "（" [实参列表] "）" | 表达式 标识符 "（" [实参列表] "）" ;
实参列表 = 实参 {"，" 实参} ;
实参 = 表达式 | 标识符 "为" 表达式 ;
属性表达式 = 表达式 ("的" | "之") 标识符 ;
索引表达式 = 表达式 "[" 表达式 "]" ;
类型引用 = 标识符 | 标识符 "." 标识符 ;
```

方法功能使用“类型名 功能名”声明，第一个参数必须是 `自己`：

```text
结构 客户：
    姓名
    累计消费
结束

定义功能 客户 升级（自己）：
    如果 自己 的 累计消费 >= 10000：
        输出("升级")
    结束
结束
```

## 运算符

从低到高的主要优先级为：`或`、`且`、比较、成员、`+ -`、`* / %`、`^`、一元 `非 -`、调用/属性/索引。比较运算符为 `=`、`==`、`!=`、`>`、`<`、`>=`、`<=`；成员运算符为 `属于`、`不属于`。

`^` 是右结合运算符，因此 `2 ^ 3 ^ 2` 等价于 `2 ^ (3 ^ 2)`。底数和指数均使用 Decimal 数字，但指数必须是可转换为 32 位有符号整数的整数；小数指数、超出范围的指数和计算溢出均返回语言级错误。

Decimal 加减乘除、取模和幂运算均为受检运算。除零、取模零和溢出返回语言级错误，不得使宿主进程 panic。

## 求值顺序

表达式按源码从左到右求值。列表项、记录值、调用接收者、位置实参和具名实参都严格按书写顺序求值，每个子表达式只求值一次。具名实参的名称不改变求值顺序。

`且`和`或`保持短路，但结果始终规范化为逻辑值。`左 且 右`在左值为假时不求值右侧并返回`否`；`左 或 右`在左值为真时不求值右侧并返回`是`。它们不返回原操作数。

赋值先求右值，再求左值中的接收者和索引。名称赋值只需在右值完成后写入；属性赋值按“右值、接收者”求值；索引赋值按“右值、接收者、索引”求值。接收者和索引均只求值一次。

`要求 条件，否则说明 信息`先求条件。条件为真时完全不求值说明表达式；条件为假时才求值说明并抛出要求错误。

## 类型与值

基础类型包括数字、浮点数、文本、逻辑、空、列表、记录、集合、字节、路径、日期时间、持续时间、金额、表格、数值数组、功能、结构实例、模块、任务、通道、流和结果。`任意`是接受所有值的抽象类型，`结构实例`是接受任意用户结构实例的抽象类型。持续时间使用带单位文本构造，例如 `持续时间("500毫秒")`、`持续时间("1.2秒")`、`持续时间("3分钟")` 和 `持续时间("1小时")`。

列表、文本、字节、数值数组、表格行列及其他序列接口统一使用一基索引。合法索引从 1 开始；零、负数、小数和越界值均返回索引错误，不会截断、取整或映射到第一项。记录属性使用 `的` 或 `之`。只有名称、属性和索引可以作为赋值左值。容器不能直接或间接包含自身；嵌套层级和集合项数受资源配置限制。

显式类型只用于边界约束：

```text
定义 金额 为 128.50，类型限定为 数字
要求 金额 的类型是 数字，否则说明 "金额类型错误"
```

所有类型检查使用同一关系：具体内建类型只接受自身；`任意`接受所有值；`结构实例`接受所有用户结构实例；具体结构类型只接受具有同一名义类型身份的实例。`数字`专指 Decimal，`浮点数`专指二进制浮点值，二者不是彼此的子类型。`金额`也不是数字的子类型。

| 操作 | 允许的类型 | 结果与规则 |
|---|---|---|
| `+ - * / % ^` | 数字与数字 | 返回数字；受检 Decimal 运算 |
| `+ - * /` | 浮点数与浮点数 | 返回浮点数；非有限结果报错 |
| `+ -` | 金额与同币种金额 | 返回金额；币种或精度不兼容时报错 |
| `* /` | 金额与数字（乘法也允许数字在左侧） | 按金额精度缩放并返回金额；不接受浮点数、逻辑或文本因子 |
| `< <= > >=` | 两个同类数字、两个浮点数、同币种金额、两个文本、两个日期时间或两个持续时间 | 不进行跨类型隐式转换 |
| `= == !=` | 任意两个值 | 同类型按值比较；不同具体类型不隐式转换并视为不相等 |
| `转数字`、`转文本`、`转逻辑`及标准库显式转换 | 按各转换契约 | 只有显式转换可以跨越数字、浮点数、逻辑、文本和金额边界 |

结构是名义类型并具有固定字段集合。每次结构声明产生不同的类型身份，身份包含所属模块；即使名称和字段完全相同，不同声明或不同模块中的结构也不兼容。构造结构只能使用字段具名实参，必须恰好提供所有字段，不接受位置实参、未知字段或重复字段。实例创建后只能修改已声明字段，不能新增字段；记录仍可动态增加键。

类型约束、赋值约束和`要求 ... 的类型是`失败时报告实际值自身的结构名，而不是抽象的`结构实例`；实际类型与期望类型同名（遮蔽声明或跨模块同名）时渲染为“另一处声明的<名称>”，使两个名义类型在诊断中可区分。

方法只能在模块文件顶层声明，并且归属于同一模块中已经声明的结构类型。不能为内建类型、抽象类型、未知类型或导入类型追加方法；同一结构不能重复声明同名方法。第一个参数必须且只能是`自己`，后续参数遵循普通调用规则。

## 作用域

程序、功能调用和模块拥有词法环境。`如果`的每个分支、条件循环的每轮、遍历循环的每轮、`尝试`、`捕获`、`最终`、每个匹配分支、匹配兜底和`任务组`都建立独立块作用域。进入任何具名或匿名功能都会建立新的功能控制域，外层循环的`跳出循环`和`继续下一轮`不能穿过功能边界。

块内可以遮蔽外层名称，离开块后恢复外层值。功能不能直接赋值外部绑定；需要修改模块或程序根绑定时必须在该功能中声明`全局 名称`。`全局`是功能级声明，写在功能内任意块都会提升到整个功能，但不传播到嵌套功能；它只能指向已经存在的根绑定。功能外使用、目标不存在、与参数冲突或与该功能的局部声明冲突均为静态错误。

匹配分支始终声明隐式绑定`当前值`，守卫和分支正文都可访问它。`记作 当前值`与该隐式绑定冲突，必须在语义分析阶段拒绝。编译器内部临时值没有源码名称，用户声明不能与内部槽发生碰撞。

## 测试语义

`测试`和四种测试钩子只能位于文件顶层，不能使用`公开`或`内部`包装。同一文件内测试名称不能重复，同类测试钩子只能定义一次。测试钩子建立局部块作用域，因此钩子中的新定义不会泄漏；需要供测试使用的状态应先在顶层定义，再在钩子中赋值或修改。

执行顺序是普通顶层声明、`测试准备`、每项测试的`每项测试前`与正文及`每项测试后`、`测试收尾`。每项测试从准备完成后的基线复制独立环境；逐项收尾和文件收尾在前序失败时仍执行。名称筛选发生在准备和正文执行前，没有匹配项时不会产生测试副作用。

| 断言 | 参数 |
|---|---|
| `断言` | 条件，可选说明 |
| `断言相等` | 实际值、预期值，可选说明 |
| `断言不相等` | 实际值、不应值，可选说明 |
| `断言包含` | 容器、成员，可选说明；文本按子串、记录按字段名判断 |
| `断言为空`、`断言不为空` | 值，可选说明 |
| `断言接近` | 实际数字、预期数字，命名参数`允许误差`默认为 0.000000001 |
| `断言会失败` | 无参功能，命名参数`信息包含`可核对错误片段 |

## 功能调用

位置参数必须在具名参数之前。实参按书写顺序求值。具名参数必须与形参名称一致；未知、重复、缺失和多余参数均在调用入口报错。一个形参只能由一个位置或具名实参绑定一次，不能同时提供。调用形状在求值默认值前完成验证，非法调用不会通过默认值副作用掩盖参数错误。

形式参数和默认值从左到右建立作用域，默认值可以引用此前已经绑定的参数，不能引用自身或后续参数。默认值在每次调用时求值，并可读取功能定义位置捕获的词法环境。形式参数名称不得重复。

记录键和结构字段在各自声明中必须唯一；重复名称是解析错误，不允许以后出现的值静默覆盖先前值。记录键既可写标识符，也可写字符串。

## 参数化输出

`参数化输出`只接收模板文本，占位符直接读取当前作用域变量：

```text
定义 订单数 为 1234567
定义 销售额 为 1234567.8
参数化输出("订单数：{订单数:千分位,0位小数}，销售额：{销售额:千分位,2位小数}")
```

占位符形式为 `{变量}` 或 `{变量:格式}`。格式支持 `千分位` 和 `N位小数`，多个选项用中英文逗号分隔；`{{` 与 `}}` 输出字面花括号。未定义变量、非数字格式化、未知格式和括号不配对均返回语言级错误。

## 错误与结果

`抛出 值`产生运行错误。语句完成状态统一为正常、返回、跳出、继续和抛出。`尝试/捕获/最终`处理这些完成状态：`捕获`只覆盖`尝试`正文抛出的错误，同级`最终`抛出的错误不会被它捕获；`最终`在所有离开路径上恰好执行一次。`最终`自身的返回、跳出、继续或抛出覆盖原完成状态；新错误保留被覆盖错误为原因。

错误对象保存类别、精确源码范围、调用栈和可选原因链。捕获后当前异常被消费，后续错误不复用旧异常；重抛、模块、任务、CLI、独立包和 Rust API 边界都保留同一错误身份。参数错误以调用点为主范围，并可附带参数定义范围；超时、取消和资源错误使用当前操作范围，不使用第 0 行。

`成功（值）`和`失败（错误）`构造结果值。统计退化样本、资源超限、权限拒绝和宿主 I/O 失败都必须返回结构化中文错误。

## 模块与并发

模块顶层声明默认公开；`内部`隐藏绑定，`公开`明确公开。可见性修饰符只能出现在文件顶层，并且只可包装定义、功能声明、结构声明、方法声明和导入语句。相对导入从当前模块目录解析，源码执行和打包使用相同规则，循环依赖会报告完整路径。

模块接口显式包含公开值、公开类型以及各类型的公开方法。普通`引入 模块`建立模块值，模块中的类型可写为`模块.类型`；`从 模块 引入 名称`在名称为类型时同时导入同一类型身份，可以直接用`名称`作为类型引用。选择导入不会复制或重新声明类型。内部值、内部类型和内部方法在模块外不可访问；公开方法可以随公开结构跨模块调用，内部方法只在其声明模块内可调用。

`任务组`会记录块内启动的所有任务，包括作为表达式启动或存入容器的任务。正常离开时等待全部任务；正文错误、子任务错误、返回、跳出、继续、抛出、超时或取消离开时，都先取消未完成任务并等待所有线程回收，再传播主完成状态。清理过程中出现的次级错误作为原因上下文保留。

跨任务可移植值包括空、逻辑、数字、有限浮点数、文本、列表、记录、集合、字节、路径、日期时间、持续时间和金额。集合往返后仍是集合；当前实现不能在任务线程中恢复用户结构的方法接口，因此结构实例、功能、模块、任务、通道、流、打开的文件/网络/数据库资源及其他宿主句柄在任务启动或发送前明确拒绝，禁止静默降级为其他类型。

## 权限与资源

文件、网络、环境、子进程和输出受权限清单控制。HTTP 每次重定向都会重新校验目标主机。执行超时同时约束语句、字节码和休眠、通道、进程、套接字、HTTP 等阻塞操作。

最大调用深度、最大值嵌套深度、最大模块加载深度、集合项数、缓冲区、输出量和执行时间均属于语言级资源预算。预算由项目权限配置给出，未配置时使用实现规定的保守默认值，并在打包时固化。解释器、内存 VM、独立包、模块和任务继承相同预算。语言求值始终运行在专用的大栈执行线程上，使调用深度预算在任何构建配置下都先于宿主栈耗尽触发。

语法嵌套深度是编译期预算，约束解析、语义检查和编译三个阶段的递归；解析同样运行在大栈线程上，超限返回结构化编译错误而不是宿主栈溢出。通道容量和并行工作者数量各有绝对上限，项目配置与命令行只能在上限之内收紧、不能放宽；超限的`通道`容量返回资源错误，并行映射的工作者数量按上限与输入长度封顶。

所有容器构造、插入、属性/索引写入、标准库结果和跨任务解码都检查循环引用、值嵌套深度和集合项数。相等、显示、序列化和深层遍历也受值深度预算约束。超限返回结构化资源错误，不得导致宿主栈溢出、panic、abort 或无界内存增长。大数据应使用流式或分块接口。

## 迁移表

| 已移除 | 现行写法 |
|---|---|
| `功能 计算（）：` | `定义功能 计算（）：` |
| `否则如果 条件：` | `否则，如果 条件：` |
| `数据 中的每个 项 都进行：` | `遍历 数据，记作 项：` |
| `只要 条件 就一直进行：` | `当 条件 时重复：` |

SQL、HTTP 方法、URL、JSON、正则表达式和 MIME 类型属于外部标准，内容保持原文，不进行中文化替换。
