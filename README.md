# 衡枢

衡枢是一门面向财务核算、报表处理和数据分析的中文编程语言。`衡`表示核算、权衡与平衡，`枢`表示数据流转和分析中枢。

衡枢的编译器、运行时、表格引擎、统计分析和打包器均使用 Rust 实现。构建产物是原生可执行文件，不依赖外部解释器或科学计算运行时。正式源码扩展名为 `.代码`。

## 产品定位

衡枢主要服务于业务、财务和数据分析人员，用于表格与文件批处理、经营分析、报表生成和可复现的自动化流程。它的目标是让程序“看得懂、写得对、错得明白”，同时保留确定、可测试、可打包的编程语言语义。

语言设计遵守三条红线：

1. 不做翻译体。中文语法应符合中文的语序和表达习惯，而不是逐词替换英文关键字。
2. 不做纯自然语言。源码必须能够被确定地解析，相同输入在解释器和字节码虚拟机中应具有相同语义。
3. 核心保持精简。表格、统计、文件、网络和数据库能力通过显式引入的标准库扩展。

## 设计约定

- 数字统一使用高精度十进制表示，避免财务计算中的二进制浮点误差；进入统计算法时发生的浮点转换必须明确处理非有限值和精度边界。
- 列表、表格和其他面向业务的序列采用一基索引，与电子表格的行列习惯一致。
- 首次声明使用 `定义`，修改已有值使用 `为`，借此尽早发现变量名拼写错误。
- 代码块以 `结束` 明确收尾，缩进只负责可读性，复制代码时不会因缩进丢失而静默改变语义。
- 名词性的从属关系使用 `的`，例如 `订单 的 金额`；动作调用由主体直接连接动作，例如 `订单 计算税额()`。
- SQL、HTTP 方法、URL、JSON、正则表达式和 MIME 类型等外部标准保持原样，不为表面上的中文化破坏互操作性。
- 每个 `.代码` 文件就是一个模块；复杂能力优先复用成熟的 Rust 生态实现，由语言层提供一致的中文语义、权限边界和错误诊断。

所有解析、检查、运行和第三方库错误都应转换为带源码位置的中文诊断，不得让用户输入触发宿主进程 panic。诊断应说明实际状态，并在能够可靠判断时给出修复建议。详细语法以[语言参考](docs/语言参考.md)为准，标准库接口以[标准库索引](docs/标准库索引.md)为准。

## 快速开始

安装 Rust stable 工具链后，在项目根目录执行：

```bash
cargo build --release

target/release/衡枢 检查 examples/销售分析.代码
target/release/衡枢 运行 examples/销售分析.代码
target/release/衡枢 打包 examples/高级统计.代码 -o ./高级统计程序
./高级统计程序

target/release/衡枢 发布 examples/高级统计.代码 -o ./发布目录
```

将 `target/release/衡枢` 安装到 `PATH` 后，可以直接使用：

```text
衡枢 检查 <程序.代码>
衡枢 运行 <程序.代码>
衡枢 测试 [目录或测试文件.代码] [--筛选 名称] [--列出] [--遇错即停]
衡枢 打包 <程序.代码> [-o 输出文件]
衡枢 审计 [项目目录] [-o 报告文件]
衡枢 缓存 <依赖名>
衡枢 发布 <程序.代码或项目目录> [-o 输出目录]
衡枢 版本
衡枢 帮助
```

省略 `-o` 时，打包产物默认使用源码文件名并移除 `.代码` 扩展名。

## 语言示例

```text
引入 表格处理
引入 统计分析

定义 表 为 表格处理 读取表格("销售数据.csv")
定义 销售额 为 统计分析 数组(表 的 销售额)

输出("平均销售额", 销售额 平均值())
输出("销售额分位数", 销售额 分位数([0.25, 0.5, 0.75]))
输出("地区汇总", 表 分组统计(["地区"], 聚合 为 "求和"))
```

更多可运行程序位于 [`examples/`](examples/)：

- `成绩分析.代码`：条件、函数和列表遍历
- `闭包核算.代码`：闭包与 Decimal 财务运算
- `语法/`：按主题覆盖核心语法、结构闭包、表格统计预测、文件数据库并发、报告隐私对账和 AI 可信分析
- `销售分析.代码`：表格读取与分组统计
- `高级统计.代码`：统计检验与线性回归
- `角色配方/`：财务、HR、销售、管理层、教师、政务和临床七条完整业务流程
- `环境.配置.模板`：AI 配置模板；复制为 `环境.配置` 后填写密钥（该文件已被 gitignore）

| 高级统计 | 稳健统计、异常值处理、预测误差、需求分类、多模型预测、安全库存、正态分布、t 检验、夏皮罗-威尔克检验和回归 |
| 系统能力 | 文件、路径、编码、JSON/TOML、正则、压缩、环境和子进程 |
| 外部连接 | 标准 HTTP 方法、URL、TCP/UDP、参数化标准 SQL 和 SQLite |
| 网络与流 | multipart 文件上传、代理、重试、协作取消、HTTP/文件/通道流和背压 |

| 工程能力 | 项目清单、依赖锁定、格式化、测试、文档、基准、LSP、审计和发布 |
| 安全边界 | 文件、网络、环境、子进程权限，以及时间、输出和集合配额 |

类型限制采用自然中文主谓结构，不使用 `变量名: 类型`：

```text
定义 金额 为 128.50，类型限定为 数字
要求 金额 的类型是 数字
要求 金额 >= 0，否则说明 "金额不能为负数"
```

外部标准保持原样。SQL、HTTP 方法、URL、JSON、HTML、CSS 选择器、正则表达式和 MIME 类型不翻译：

```text
引入 数据库
定义 连接 为 数据库 打开SQLite("财务.db")
定义 记录 为 连接 查询("SELECT * FROM sales WHERE region = ?", ["华东"])
```

系统默认信任用户代码；网络、环境变量和子进程可直接使用。需要 CI 或嵌入场景的最小权限时，再通过权限配置或命令行显式收紧：

需要配置 AI Key 等参数时，在中文源码目录或打包程序运行目录放置固定名称的 `环境.配置` 文件，例如 `HENGSHU_AI_API_KEY=...`；文件格式与常见 dotenv 相同，未找到文件时兼容读取进程环境。

```text
衡枢 运行 分析.代码 --允许 文件:./数据 --允许 网络:api.example.com
衡枢 运行 任务.代码 --最长执行时间 30秒 --最大调用深度 1024 --最大输出字节 1048576 --最大缓冲字节 67108864
```

未显式配置时，单次缓冲输入默认最多 64 MiB、集合物化最多 100 万项、程序输出最多 16 MiB，源码文件最多 16 MiB。更大数据应使用 CSV、Parquet、HTTP 和文件流式接口。

动态网页采集通过本机 Chrome 或 Chromium 的标准调试协议完成，支持声明式字段选择、自动翻页、动态内容加载标志和随机等待。它需要网络与子进程权限；发布示例集中在 `examples/语法` 与 `examples/角色配方`，网络接口用法见用户手册。

## 独立打包

`衡枢 打包` 会解析并检查主程序，遍历完整语句树递归收集本地 `.代码` 模块，将带版本、常量池、指令、源码映射和模块身份映射的验证字节码及 SHA-256 校验值嵌入运行时副本。不同目录中的同名相对模块使用不同的包内身份。生成的程序不再访问原始源码或模块，并强制执行打包时固化的权限与资源配额。

平台发布脚本位于 `scripts/package-platform.sh` 和 `scripts/package-platform.ps1`：macOS 生成 CLI 与签名 `.app`，Linux 生成 CLI/AppDir/AppImage，Windows 生成 CLI 与无控制台 GUI `.exe`。每个输出目录包含 `SHA256SUMS`、依赖清单和 `BUILD-MANIFEST`；`衡枢 验证包 <程序>` 可在不运行载荷的情况下检查包类型和载荷摘要。

发布给开发者的宿主程序是未内嵌用户载荷的 Release `衡枢` 和 `衡枢GUI`。`衡枢` 是唯一的开发者终端入口：执行 `衡枢 打包 ./工资条.代码 --界面 --工具 工资条 -o ./发布/工资条` 时，会从自身同目录查找 `衡枢GUI` 宿主并生成 GUI 成品。`衡枢GUI` 只负责作为成品 GUI 载荷的宿主，不接收开发者打包命令。

省略 `--界面` 时生成 CLI 成品；需要 GUI 成品必须显式加上 `--界面`。`--工具 工资条` 是从用户项目 `衡枢.toml` 的工具清单读取 schema，不是把工具名作为位置参数传入。

由 `衡枢 打包` 生成的用户程序（包括 `.app`、`.exe` 和 AppImage）是最终载荷，只负责运行该用户程序，不能再次作为编译器打包其他 `.代码`。

打包产物与构建平台和 CPU 架构对应。macOS、Linux 和 Windows 应分别构建和发布；当前 macOS 打包流程会重建 Mach-O `__LINKEDIT` 并生成 ad-hoc 代码签名。

## 工程结构

```text
src/lexer.rs       中文词法器
src/parser.rs      Pratt 表达式与语句解析器
src/ast.rs         可序列化 AST 中间表示
src/bytecode.rs    稳定字节码格式与载荷验证器
src/compiler.rs    AST 到字节码编译器
src/value.rs       动态值、Decimal、函数和表格值
src/runtime.rs     解释执行编排与核心语句/表达式求值
src/runtime/       环境、预算、调用、对象访问和模块加载
src/vm.rs          字节码虚拟机与差分执行入口
src/stdlib.rs      标准库统一分派和 I/O 上下文
src/stdlib/        进程、网络、路径和纯工具实现
src/table.rs       CSV/XLSX 和表格关系分析
src/analysis.rs    数据分析分派、Parquet、检验和回归
src/analysis/      基础统计与线性代数纯算法
src/pack.rs        单文件打包、校验和与平台处理
src/security.rs    权限、路径边界和资源限制
src/release.rs     可复现发布归档和校验文件
src/api.rs         最小稳定 Rust 嵌入接口
src/cli.rs         中文 CLI 和内嵌程序入口
src/main.rs        进程退出码适配
tests/             Rust 集成测试与测试数据
examples/          可直接运行的 `.代码` 示例
```

产品定位和稳定设计约定记录在本文，架构边界见 [架构文档](docs/架构.md)。
用户请先阅读 [用户手册](docs/用户手册.md)、[语言参考](docs/语言参考.md)、[标准库索引](docs/标准库索引.md)、[数据语义](docs/数据语义.md) 和 [测试指南](docs/测试指南.md)。Rust 程序可通过 [嵌入 API](docs/嵌入API.md) 调用检查、执行和编译能力。面向 AI 工具的生成约束位于 [衡枢 Skill](skills/hengshu/SKILL.md)，API 稳定性规则见 [API稳定性](docs/API稳定性.md)。
